# WARN Notice Register v1.0.0 — source-only release

## Data boundary

This release replaces the prior main-branch data product with one source-only
agency build observed on 2026-09-24. The immutable
[source bundle](../data/source_snapshots/2026-09-24-agency-only-ny-ga-orhist-txhist-mo-oh-v1.tar.gz)
has SHA-256 `858d1493a86f2a8012f2ce50844b316ab36731ee4482987a93893baedc457de7`.
The [replay report](../data/source_snapshots/2026-09-24-agency-only-ny-ga-orhist-txhist-mo-oh-v1-report.json)
and [exception ledger](../data/source_snapshots/2026-09-24-agency-only-ny-ga-orhist-txhist-mo-oh-v1.exceptions.jsonl.gz)
preserve the source accounting. The database contains **71,490 admitted notices,
79,261 versions, 7,482,177 reported affected workers, and zero inferred links**.
The export contains **974 verified agency observations** with explicit admission
or exclusion status; the separate ledger accounts for **11,888** other held
source rows. These are source observations and dispositions, not a count of
missing legal filings.

The latest pre-release `main` dump at `7147e45` held **92,313 notices** and
**9,702,576 workers**. The new build has 20,823 fewer notices and 2,220,399
fewer reported workers. The [state-by-state delta](release-v1-state-delta-2026-09-24.csv)
shows every change. The largest count reductions are Georgia (3,231), Kansas
(2,604), New York (2,120), Kentucky (1,760), and Washington (1,411). The
former integrated Big Local News data and other unsupported historical rows
are no longer admitted solely because an earlier product contained them.
These differences are a change in evidence policy, not evidence that the
underlying layoffs did not happen.

## Coverage limits

- **Iowa and Kentucky have zero admitted notices** under this source policy.
  Their old main-branch counts were 965 and 1,760. Source rows remain preserved
  where available, but current identity/provenance rules do not support
  publishing them as canonical notices.
- Kansas has 206 admitted notices. Its public portal may support additional
  original-source recovery, but the excluded historical capture mixes WARN
  and Non-WARN rows and is not admitted wholesale.
- Ohio's 2015–22 agency tables are included; 2023–25 lacks a verified complete
  agency index. Missouri's older rapid-response register remains mostly held.
  Georgia before 2018 and several other state periods are incomplete.
- Georgia, Iowa, Kentucky, Oregon, and Tennessee are **archive-only** in the
  registry. Their old upstream collectors append the excluded historical
  mirror, so scheduled collection is paused until direct agency-only adapters
  are verified. The initial rebuilt database contains no live collector-run
  telemetry; **Unknown** health means no release-day live check, not success.
- Receipt, posting, and layoff dates are not relabeled as legal employer notice
  dates. Unsupported dates and workers stay null. State counts reflect agency
  reporting practices and conservative event identity rules.

## Release checks and rollback

Two source-only replays in separate local Python environments matched counts,
stable notice/version fingerprints, the exception ledger, and the SQLite file
hash. The rebuilt SQL dump restores to a database with the same fingerprints,
integrity `ok`, and zero foreign-key errors. The national and state CSVs,
974-row observation export, regression baseline, and pinned-date site data are
checked against the same database. The release commit must also pass the full
Python suite, frontend tests/build, and deployment reconciliation on the
Ubuntu runner before the site is published.

The prior main commit `7147e45` and its SQL dump provide the rollback point.
Do not mix its CSVs, database, or site files with this release. Later scheduled
scrapes may add agency records after v1.0.0; they must pass the regression and
cross-artifact checks before deploying.
