# Florida collector year-link repair

The saved Florida run failed before reading WARN rows. The upstream scraper requests a landing page, selects `div.contact-details a.externalIcon`, and takes the first discovered year. The saved response supplied no matching links, so the scraper raised `IndexError`. The agency's REACT service still exposes [year-specific 2026 records](https://reactwarn.floridajobs.org/WarnList/Records?year=2026), [2019 records](https://reactwarn.floridajobs.org/WarnList/Records?year=2019), and [2015](https://reactwarn.floridajobs.org/WarnList/viewPreviousYearsPDF?year=2015) and [2018](https://reactwarn.floridajobs.org/WarnList/viewPreviousYearsPDF?year=2018) PDF archives.

The local `warnlive.fetch.patches.fl` collector now addresses the 2015–2018 PDFs and 2019–current HTML years directly. It retains the upstream row and PDF parsers, but uses a bounded HTML pager with 45-second requests, a 100-page limit, same-year links, and expected table-column validation. Historical years must yield rows; a structurally valid zero-record current-year page is allowed. It validates row width and a minimum total, then writes `fl.csv` only after the complete capture succeeds. A failed page leaves the prior CSV untouched. The registry routes Florida through this patch.

Five focused tests pass, including bounded HTTP failure and an empty current year. An offline smoke run using the existing cached PDFs and HTML pages produced **3,230 rows**, with the same five columns and the **same multiset of rows** as the prior saved `workdir/raw/fl.csv` capture. Ordering differs because the patch traverses years chronologically; no row content was added or removed in this fixture comparison.

The runtime environment could not resolve the REACT host for a live request. The current collection-health blocker therefore remains **pending a fresh networked fetch** and verifier run on the release code. The Florida source column is labeled `State Notification Date`; this repair changes collection only. It does not independently establish that this day equals employee receipt of legal notice, and it does not change the timing cohort's date policy.
